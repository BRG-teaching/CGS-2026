### Task 1 - Solve by hand

Using graphic statics, design a possible arch-cable structure for each of the two given load cases, and draw the corresponding force diagrams. Indicate the direction of the reaction forces, and mark tension forces in red, compression forces in blue and reaction forces in green. Solve this task in the separate file provided on Moodle.

### Task 2 - Interactive drawings

Build both cases from Task 1 as interactive equilibrium drawings in Grasshopper. Use the Rhino file provided on Moodle.&#x20;

### Task 3 - Combine the two systems in 3D

Design a simple 3D system in which one of your two arch-cables carries the other. Paste screenshots below. Then change one parameter of your choice (for example a load or a support position) and paste a second set of screenshots.

Hints:

* Remember that the reactions of the upper structure, reversed, become the point loads of the lower one.
* In your 2D drawings the vertical direction is Y; in the 3D system it is Z.
